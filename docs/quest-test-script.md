# Physical Quest tester script (not yet executed)
Record headset model (Quest 3 or 3S), OS version, Quest Browser version, date, HTTPS URL/build hash, seated/standing, hand-tracking setting and test duration.

1. Cold load trusted HTTPS. Enter XR. Confirm hand permission and both hands render/track.
2. With one hand, pinch the cyan plane, draw the Level 1 guide, release. Repeat left-handed. Record missed strokes or accidental button actions.
3. Confirm LUMA's profile and materialized geometry agree, traveler crosses, labels readable from seated reach.
4. Level 2: draw the short guide, observe actual failure and highlighted missing columns, redraw the extension, confirm replan and crossing.
5. Clear, invalid tiny shape, Undo, reset, pause/resume, mute, high contrast, reduced motion and recenter. No dead controls.
6. End session via system menu unexpectedly, return to browser, re-enter and play again. Background/foreground app and check recovery.
7. Test for 10 minutes with repeated drawings. Capture device FPS where observable (target ≥60), thermal/perceptual smoothness, comfort, text legibility and hand reliability. Desktop emulation statistics are not substitutes.
8. Report blocking bugs, reproducible steps and original footage/screenshots. Mark every unexecuted check explicitly.
