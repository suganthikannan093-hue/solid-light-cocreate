# Gameplay recordings
`solid-light-xr-demo-v3.mp4` is the primary competition demo (recorded 14 Nov 2026 on commit 5f2d8e6, after the XR layout fix that gives LUMA's depth panel its own space to the right): 96.5 seconds, 1280×720 H.264/AAC 48 kHz stereo, the same IWER Quest 3 emulator hand drawing of Incomplete Span and the same marin narration clips as v2, with burned-in captions (`../solid-light-xr-demo-v3.srt`). Raw capture `solid-light-xr-demo-v3-raw.webm`; timeline `../xr-demo-v3-timeline.json`; manifest `../xr-video-manifest-v3.json`; frame checks `../screenshots/xr-demo-v3-frames/`; per-chapter XR and desktop layout stills `../screenshots/xr-layout-v3/`. Render with `SL_VARIANT=-v3` (see below).

`solid-light-xr-demo-v2.mp4` was the primary demo until v3; its right-side depth panel overlapped the centre and toolbar (re-recorded 14 Nov 2026 on commit 7efafe4, after the 12 Nov authorship-colour changes): 96.3 seconds, 1280×720 H.264/AAC 48 kHz stereo, real IWER Quest 3 emulator hand drawing of Incomplete Span (short ribbon, LUMA missing-length diagnosis, human extension, traveler crossing) with burned-in captions (`../solid-light-xr-demo-v2.srt`). Player geometry is cyan/teal, amber is LUMA-only. Narration uses the unchanged pinch-only script in `../xr-narration.json`, regenerated with OpenAI marin (the original WAVs were not on the recording machine). Raw canvas capture: `solid-light-xr-demo-v2-raw.webm`; timeline: `../xr-demo-v2-timeline.json`; manifest: `../xr-video-manifest-v2.json`; frame checks: `../screenshots/xr-demo-v2-frames/`. Capture is the official Immersive Web SDK emulator, not a physical headset. Reproduce with `node scripts/record-xr-demo.mjs` (rename the raw/timeline outputs to the -v2 names), then `FFMPEG=ffmpeg FFPROBE=ffprobe SL_VARIANT=-v2 SL_FONTSDIR=/usr/share/fonts/truetype/liberation SL_FONT='Liberation Sans' python3 scripts/render-xr-demo.py`.

`solid-light-xr-demo.mp4` is the previous primary demo, kept for reference: 100.9 seconds, 1280×720 H.264/AAC, recorded 10 Nov before the 12 Nov colour changes, pinch-only OpenAI marin narration, real IWER hand drawing of Incomplete Span (short ribbon, LUMA missing-length diagnosis, human extension, traveler crossing). Captions contain pinch-only language. Capture is the official Immersive Web SDK Quest 3 emulator, not a physical headset.

`solid-light-cocreate-narrated.mp4` is the supplementary four-chapter desktop demo: 161.60 seconds, 1280×800 H.264/AAC, captions, real game audio and AI-generated conversational marin narration. It shows the four-chapter default journey, actual failures/repairs, verified crossings and recovery/accessibility features. It is real desktop gameplay, not headset footage, and uses no cloud inference.
