# Reviewer instructions
Public URL: pending approved deployment. Desktop: open the URL in a current browser. Quest: use Quest Browser over trusted HTTPS, select Enter XR, allow hand tracking, use spatial controls below the bridge. Physical Quest behavior remains unverified; see QA report.

1. Level 1 starts automatically. Pinch-and-drag (desktop: click-and-drag) a closed ribbon around the dotted cyan-plane guide. Release. LUMA tests side profiles and the traveler crosses a validated bridge.
2. Select Level 2. Trace its intentionally shorter guide. Wait for LUMA's real missing-length diagnosis and amber column highlight.
3. Redraw a ribbon extending left-to-right through all highlighted columns. Only your drawing changes the front silhouette. LUMA replans and the traveler crosses.
4. Undo, Clear, Reset and Pause/Resume recover freely. Use Help for a reminder. High contrast, Reduced motion and Mute are available. One pointing hand suffices; no two-hand gesture or voice input required.

All critical gameplay uses the offline planner. Network is needed to initially load a hosted app; there is no runtime AI network dependency. This release does not include a service worker, so a cold load with no cached assets requires connectivity.

Level 3 and Cloud LLM are not available. Invalid shapes give corrective guidance instead of a fabricated crossing. Already sufficient Level 2 drawings may succeed directly.
