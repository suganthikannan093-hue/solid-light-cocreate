# Reviewer instructions
Public URL: https://suganthikannan093-hue.github.io/solid-light-cocreate/ . Desktop: open the URL in a current browser. Quest: use Quest Browser over trusted HTTPS, open Settings and select Enter XR, allow hand tracking, use spatial controls in the primary spatial row. Physical Quest behavior remains unverified; see QA report.

Returning players see Continue vs New game (mouse or pinch); comfort and audio settings restore from localStorage. A first visit starts Chapter 1 automatically.

1. Level 1 starts automatically. Pinch and hold a closed ribbon around the dotted cyan-plane guide, then release. LUMA — a deterministic local search planner, not an LLM — tests side profiles and the traveler crosses a validated bridge.
2. Choose Next level to enter Incomplete Span. Trace its intentionally shorter guide. LUMA’s solid visibly falls short, with a warm-tinted volume and a “falls short” prompt. That is the authored failure beat.
3. Redraw a longer ribbon through the amber gap to B. Only your hands can add length. LUMA replans depth; the traveler crosses under a REPAIRED TOGETHER caption, light and a success motif. Open How LUMA thinks to see the last search decision. In a headset, lean or look right to inspect the true side silhouette; on desktop, right-drag to orbit.
4. Undo, Clear, Reset and Pause/Resume recover freely. Use Help for a reminder. High contrast, Reduced motion and Mute are available. One pointing hand suffices; no two-hand gesture or voice input required.

All critical gameplay uses the offline planner. Network is needed to initially load a hosted app; there is no runtime AI network dependency. This release does not include a service worker, so a cold load with no cached assets requires connectivity.

5. Next level opens Light Garden. A low ribbon has a path but no shelter; keep the lower loop and draw a second closed loop around the upper canopy guide. Compare Sturdy/Efficient in Settings.
6. Next level opens Last Spark. A broad protected bridge exceeds the light budget. Tighten its outer edges through the highlighted strips while keeping the banks connected. Next starts a workshop preset; four presets vary the constraints.

Cloud is off by default. OpenAI connectivity has been separately verified, but no public proxy is deployed. Invalid shapes give corrective guidance instead of a fabricated crossing. Already sufficient drawings may succeed directly. Chapter practice and accessibility toggles are in Settings.
