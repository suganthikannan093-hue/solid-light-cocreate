# Narrated gameplay demo
Primary upload: `recordings/solid-light-xr-demo-v2.mp4` (96.3 s, re-recorded 14 Nov on the current build; the 10 Nov `recordings/solid-light-xr-demo.mp4`, 100.9 s, is kept for reference). Canonical XR narration is `xr-narration.json`; timings in `xr-voice-timing.json` and `xr-demo-v2-timeline.json`. Voice: OpenAI marin, pinch/VR only — pinch-only language. The clip is one Incomplete Span loop: pinch a short ribbon, LUMA cannot add length, the player extends the outline, the traveler crosses. Capture is official IWER Quest 3 hand input, not a physical headset.

Supplementary four-chapter desktop capture remains `narration.json` / `voiceover-timing.json` / `solid-light-cocreate-narrated.mp4`. Voice: OpenAI marin, an AI-generated conversational voice, separate from LUMA's original game motifs.

Show the moving closed-loop example, a real first drawing and traveler crossing, the authentic missing-span failure and human repair, recovery/accessibility controls, canopy failure and repair, then budget failure and trim. End on the actual completed structure. No fabricated geometry, planner state or physical headset footage. Default capture uses no cloud inference.

`node scripts/record-demo.mjs` records real pointer gameplay from the production preview. `python3 scripts/render-demo.py` adds narration, recorded game audio and synchronized captions, produces H.264/AAC MP4 and enforces the three-minute maximum. Intermediate tools/audio stay in ignored `.tmp/`. Public YouTube/Vimeo upload remains an owner action.

Narration revision: the system voice was replaced with OpenAI marin using a conversational script and restrained delivery instructions, following https://developers.openai.com/api/docs/guides/text-to-speech . `node scripts/create-natural-voiceover.mjs <private-key-file>` generates cached speech segments outside source control. The renderer preserves pitch at 0.92× pace, adds short scene-specific pauses and regenerates captions. This remains clearly disclosed AI-generated narration. Gameplay footage and game audio are unchanged.
